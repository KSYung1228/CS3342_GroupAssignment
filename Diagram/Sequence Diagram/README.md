## Visual Paradigm note
Visual Paradigm `.vpp` is a proprietary project database format (SQLite-based). It is not safe to hand-author directly.

To get a `.vpp` file:
1. Open Visual Paradigm.
2. Import or recreate the sequence using `ShopRental_MainFlow_Sequence.puml`.
3. Save the project as `.vpp`.
