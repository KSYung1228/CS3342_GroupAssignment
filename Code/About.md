### 📁 Code & Program Storage

This folder contains the complete **source code** and **functional program** for the Commercial Shop Rental Management System. It serves as the implementation layer for the business logic and entity relationships defined in the project documentation.

---

### 📦 Core Contents
* **Source Files**: All Java classes implementing the system's architecture, including entity definitions for Buildings, Shops, and Merchants.
* **Business Logic**: The programmed rules for rent calculation, utility compliance, and lease lifecycle management.
* **System Engine**: The core executable logic that processes admin approvals, merchant registrations, and payment tracking.

### ⚙️ Primary Functions
The code stored in this directory is responsible for:
* **Data Management**: Storing and updating building information and shop inventories.
* **Validation**: Programmatically enforcing "no open flame" restrictions and facility requirements for different shop types.
* **Contract Workflow**: Handling the transition of lease contracts from creation to signing and termination.
* **Financial Processing**: Managing the logic for calculating rent ratios and recording payment statuses.

### 🚀 Program Execution
This directory includes the main entry point required to compile and run the application. Once executed, the program initializes the management environment, allowing for the simulation of the full shop leasing lifecycle within the Hong Kong real estate context.
